<h1 align="center">
  <b>reChat</b>
</h1>

<p align="center">Simple twitch chat
</p>

## Features:

  - 7TV emotes
  - Twitch emotes
  - Twitch badges
  - In chat images(jpg, jpeg, png, gif) with NSFW recognition
  - Link generator
  - Black list
  - Fonts

## In process:

  - 7TV badges/colors
  - Support custom CDN link and formats(mp4, webm, webp)
  - FM highlight
  - Twitch events highlight
  - YouTube and Kick integration
  - Twitch Bot functions
  - Descktop app
